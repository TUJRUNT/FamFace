FamFace

Download the desktop version of your chat app and share it with others.

Get the App

Click the button for your platform after building the installer.

Windows macOS Linux

After packaging, place the generated installer files in website/downloads/ for them to work here.

How to build

  1. Install dependencies: npm install
  2. Build the desktop app: npm run dist
  3. Copy the generated files from dist/ into website/downloads/
  4. Open website/index.html in a browser or host the folder on any static web server.

FamFace built with Electron and Socket.io.
